# Catatan perubahan: SWI-PRO-MET-201-018 (Final Tailings and TSF Return Water) ke format Heritage

Aturan umum sama dengan catatan sebelumnya. Teks hazard disalin otomatis dari file lama. Tidak ada padanan Martabe. Hasil: 7 halaman.

## Pemetaan
| Format lama | Format Heritage |
|---|---|
| Langkah 1 (line mengalir, titik tidak buntu) | Step 1 Pre-start Check |
| Langkah 2-3 (flush, ambil sampel, pH segera) | Step 2 Final Tailings Sampling |
| Langkah 4-5 (per cent solids, filter dan botol) | Step 3 Solids and Cyanide |
| Langkah 6-7 (sampel return water, catat flow, density, waktu) | Step 4 Return Water Sampling |
| Section 7 dan 8 | Step 5 Completion and Clean Up |

## Hal yang ditulis baru
- Hazard a), b), c) per step dan kotak CAUTION Step 2 dari hazard dokumen.
- Kotak emergency 5 butir (HCN, cyanide exposure, skin/eye, fall, slip). Tidak ada butir moving equipment karena SWI ini tidak punya hazard tersebut.
- Butir "second person in the area" di Pre-start. Section 2 digabung ke Step 1. Classification dibuang; Area ke Description of work.
- PPE 8 butir (dengan harness, sesuai SWI lama).
