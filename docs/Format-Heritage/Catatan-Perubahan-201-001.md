# Catatan perubahan: SWI-PRO-MET-201-001 ke format Heritage

Template: `MM-4034-033-OR-03-SWI-PRO-LAB-304-008-...-RevA.docx` (folder ini). File hasil dibangun ulang dari template tersebut oleh `build_201_001.py`, jadi font, warna, tabel, header, footer, cover, dan ikon PPE identik dengan heritage. Isi teknis 201-001 dipertahankan.

## Format
- Format lama (Calibri 9,5 pt, tabel biru tua, 9 bagian bernomor) diganti format Heritage: cover dengan logo dan foto, header "Safe Work Instruction", footer Document/Revision, border halaman emas.
- Halaman: 3 menjadi 7 (cover + 6).

## Pemetaan isi
| Format lama | Format Heritage |
|---|---|
| Tabel identitas (No. dokumen, JSEA, Date, Rev) | Part 1: Title, Issued Date 11/08/2026, Next Review Date 11/08/2027, Document Owner, JSEA ID; Rev A dan tanggal di footer |
| 1 Task and Scope (3 setpoint, tabel tag, frekuensi, parent procedure, register line) | Part 2: Description of work. Tabel tag diubah menjadi baris teks "tag - deskripsi" |
| 3 Hazards specific to this task (7 hazard) | Part 2: Potential Hazards, format "Hazard — Control" |
| 4 PPE | PPE Requirements (hal. 2) dan baris ikon PPE (Part 2) |
| 2 Who may do this | Digabung ke langkah 1 Pre-start Check (trained, JSEA, authorised) |
| 5 Before you start + Equipment required | Step 1 Pre-start Check + Equipment Required |
| 6 Steps (7 langkah) | Part 3, dikelompokkan jadi step 2-5 |
| 7 On completion + 8 Records | Step 6 Completion and Clean Up |
| 9 Reference | Tabel Referenced Documents (ditambah HM-PRC-VXX-PRO205, JSEA, register) |

## Perubahan isi yang perlu Anda cek
1. Kalimat hazard dan langkah dipendekkan ke gaya imperatif heritage, tanpa menghilangkan kontrol.
2. Langkah 4 lama (pH) dipecah dua kalimat; langkah 5 lama (% solids) dipecah empat bullet.
3. Kolom hazard huruf a), b), c) per langkah ditulis baru dari Section 3 lama (heritage mewajibkannya).
4. Dua kotak CAUTION (langkah 2 dan 5) disusun dari kontrol hazard lama.
5. Kotak emergency halaman terakhir (butir 2 moving equipment dan butir 5 slip/fall/lifting) ditulis baru; butir 1, 3, 4 diadaptasi dari 304-008. Mohon diperiksa HSE.
6. Baris ikon PPE dibiarkan 10 ikon seperti heritage (termasuk fall restraint, belum disaring).
7. Document Owner diisi "Processing" seperti heritage.
8. Kolom Visual Reference dikosongkan seperti heritage.
9. Banner "NOT FOR USE" dan keterangan safety-critical (khusus 304-008) tidak ada.
10. Kolom "Area 021 Scrubber" dan "Classification Operating" tidak punya tempat di heritage; Area ditulis di Description of work, Classification dibuang.
